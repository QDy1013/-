# 西工大课表（v0.18，兼容v0.17存档）

## 一键导入

入口：更多 → 我的课表，学校选择“西北工业大学”。输入翱翔门户账号和密码，点击“一键导入”，App 自动完成学校认证、打开个人课表、获取默认当前学期和开学日期、保存并进入周课表。不需要手动打开教务页面、选择学期、点读取或确认预览。

学校如果要求滑块、图片验证码或二次认证，会自动显示校方页面让本人验证，通过后自动继续。应用不代做或绕过安全验证，这一步取决于校方要求。

已有有效会话时，右上角同步图标可直接重新同步；会话失效后回到账号密码表单。“课表设置 → 使用其他账号导入”切换账号。输入新凭据导入时，先清除本 App 旧 WebView 会话，避免误导入其他账号的课表。空课表、未知结构、认证失败、超时或保存失败均保留原课表。

## 周课表与交互

- 七列对应周一至周日，按节次排列。左侧显示接口提供的上课开始时间，不编造作息。
- 左滑下一周、右滑上一周；从课程色块上起手也可换周，滑动不误开详情。上下滑只滚动课表。
- 换周保留滚动位置，首尾周不能越界。顶部“本周”回到当前教学周，教学周标题可直接选周，箭头也能换周。
- 今天的日期与列高亮，同一课程颜色稳定；星期标题和课程格共用列坐标。
- 点色块查看完整课程、时间、教室、教师和具体周次。重叠课程聚为可展开的组，避免互相遮盖。
- 日期校准、未排课课程和删除课表收进设置；未排课课程不推断时间地点。

课表使用独立本机存档，不生成消息卡片、不覆盖个人档案课程。群消息中的更正不自动修改课表，需要重新同步教务系统。删除课表与“清空待办和近期消息”分别处理对应数据。

## 页面与接口依据

- [教务系统](https://jwxt.nwpu.edu.cn/student/home)；SSO `/student/sso-login`；个人课表 `/student/for-std/course-table`。
- [校方查看课表通知](https://jiaowu.nwpu.edu.cn/info/1158/29468.htm)说明通过翱翔门户进入教务系统。
- [统一认证页面](https://uis.nwpu.edu.cn/cas/login)使用 `#fm1` 表单及 `#username`、`#password`。兼容电脑版登录按钮和手机页 submit 按钮。
- [公开接口调用代码](https://github.com/qllokirin/nonebot-plugin-npu/blob/HEAD/nonebot_plugin_npu/nwpu_query.py)使用 `/student/for-std/course-table/semester/{semesterId}/print-data/{studentAssoc}?hasExperiment=true`。
- [公开字段使用代码](https://github.com/qllokirin/nonebot-plugin-npu/blob/HEAD/nonebot_plugin_npu/draw_course_schedule_pic.py)读取 `studentTableVm.activities`、作息布局及学期起始日期。

程序独立编写，公开代码仅用于确认接口和字段。读取网页默认学期及明确学生身份，不写死编号，不能唯一确定身份或识别结构时停止，不猜测。

## 凭据与存档

v0.17 申请 INTERNET 以访问校方网页。群消息识别仍在本机运行，导入组件不读取或上传群消息存档。

账号密码在本机表单短暂保留，仅交给精确的 HTTPS `uis.nwpu.edu.cn/cas/login` 及其同源表单。点击校方现有按钮，保留其加密和安全验证处理，不直接调用绕过校方处理的表单提交。提交后清除应用临时密码，不将凭据写入设置、文件、诊断日志或公开测试数据。登录页禁用截图与最近任务预览。

WebView 只允许 HTTPS 西工大域名导航，禁用文件访问、混合内容，不跳过证书错误。没有 JavaScript 原生桥接；Java 轮询固定状态和规范化课表结果，不读取 Cookie 或完整学生资料。校方会话 Cookie、站点存储可保留在本机用于后续同步，不是应用自行保存的密码。

课表独立存于应用私有目录 `timetable.json`，通过带大小上限的 AtomicFile 保存。只有非空、通过校验且具有可靠开学日期的课表会覆盖旧存档。具体上课周次原样保存，不把单双周扩大为连续周。

## 构建

独立测试版：`python android/build.py --sdk <SDK路径> --preview`，生成 `nopalou-preview.apk`，应用 ID 为 `com.nopalou.preview`、名称“楼外·课表测试”。可与原版并存，不读取或覆盖原版待办；测试课表无需开启通知读取权限。

标准版需原签名：`python android/build.py --sdk <SDK路径> --keystore <旧版签名密钥库路径>`。本次调试签名与仓库旧 APK 不同，不可直接覆盖安装；不要为安装而卸载旧版，以免丢失本机待办。

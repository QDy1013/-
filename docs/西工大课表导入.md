# 西工大课表导入（v0.17）

入口：更多 → 我的课表 → 从西工大教务一键导入。通过 `/student/sso-login` 进入学校统一身份认证，使用翱翔门户账号登录，完成验证码或身份选择，打开个人课表并选择学期，点击“导入当前学期”。预览核对课程、具体上课周次、节次、教师、教室及第1周周一，保存后替换本机课表。首次导入仍需本人登录，后续登录有效时可直接读取。

如果网页显示教务系统自己的“账号登录”页，点击顶部“统一认证”切回 SSO 入口，不要直接把翱翔门户账号用于教务独立账号表单。首轮手机测试中，直接从课表地址进入时出现“用户名或密码错误”；改为 SSO 入口后本人登录成功。

课表保存后按周查看，支持上一周、下一周、回到本周和校准开学日期。接口提供作息表时显示钟点；未提供时只显示节次。周次严格按接口数组保存，不把单双周扩成连续周。不根据群通知自动改动课表。未排课课程仅显示可读取的名称，不能推断时间地点。

空课表、未知格式、HTTP 错误、登录过期、超时及取消预览都不保存；保存使用 AtomicFile，保留上一次完整存档。课表独立存于应用私有目录的 `timetable.json`，不会生成群消息卡片或覆盖档案中的课程。删除课表在课表页操作，“清空待办和近期消息”仍只处理其原有范围。

## 校方页面与数据结构依据

- 入口：[翱翔教务](https://jwxt.nwpu.edu.cn/student/home)，课表页 `/student/for-std/course-table`。
- [校方查看课表通知](https://jiaowu.nwpu.edu.cn/info/1158/29468.htm)说明通过翱翔门户进入教务系统查看课表。
- [接口调用的公开实现](https://github.com/qllokirin/nonebot-plugin-npu/blob/HEAD/nonebot_plugin_npu/nwpu_query.py)使用 `/student/for-std/course-table/semester/{semesterId}/print-data/{studentAssoc}?hasExperiment=true`。
- [数据字段的公开使用代码](https://github.com/qllokirin/nonebot-plugin-npu/blob/HEAD/nonebot_plugin_npu/draw_course_schedule_pic.py)使用 `studentTableVm.activities` 下的 `courseName / weekIndexes / weekday / startUnit / endUnit / teachers / room`，以及 `timeTableLayout.courseUnitList` 和 `arrangedLessonSearchVms[].semester.startDate`。

实现为独立编写的适配器，以上代码用于确认接口与字段，没有复制其程序。学期读取网页当前选中项，身份来自个人课表路径、明确的学生字段或单一身份按钮；身份不明确时请用户在校方网页选择，不猜测身份或写死学期编号。

## 网络与登录

v0.17 新增 INTERNET 权限。WebView 只允许 HTTPS 西工大域名导航，使用校方自己的登录页；不绕过验证码、校内网限制、412 拦截或证书检查。账号密码由校方登录页面处理，应用代码不读登录表单，不把账号密码写入档案或诊断日志。

读取脚本仅在精确的 `jwxt.nwpu.edu.cn` 个人课表路径执行，用已有会话发起一次同源 GET 请求。无 JavaScript 原生桥接，Java 通过 evaluateJavascript 读取带本次标记的规范化课表结果，不读取完整网页、Cookie 或原始学生信息。重定向、失效会话和未知结构停止导入。

WebView 可能在本机保留会话 Cookie 和站点存储以便下次登录。导入页的“退出教务登录”清理本 App 的 WebView Cookie、站点存储和网页缓存；已保存课表保留。没有自行编写的登录服务端或课表中转服务器。

## 已验证与待验证

已使用合成数据验证：当前学期选择、学生身份选择、具体单双周、教室变更、作息、未排课名称、缺失字段、空课表、非法日期、错误节次、412 和过期登录响应；Java 验证星期日期换算及存档格式往返。测试不含真实个人信息。

自动测试：`node eval/test_nwpu_import.cjs`。Java 的 `android/test/TimetableTest.java` 需要在 JVM 测试类路径提供 org.json（Android 系统自带该库，JDK 不包含）；向脚本传输出路径可生成其模拟输入：`node eval/test_nwpu_import.cjs <fixture.json>`。

2026-11-06 的独立测试版已在本人手机验证：学校 SSO 登录成功，读取到非空课表并弹出预览；保存后正确显示当前周，可切换下一周，结束应用进程后重新打开仍可读取已保存课表。没有把真实课程、身份信息或登录凭据写入公开测试数据。

仍未逐项手工核对所有课程字段，也未在手机上完成断网、登录失效、空学期和退出会话的完整验收。开发环境直接访问教务入口仍可能返回 412。后续可继续检查：

1. 登录、验证码、身份选择、学期切换能正常完成。
2. 与网页对照课程数、单双周、实验课、教室、教师和作息；校准第1周周一。
3. 保存后断网、重启 App，切换周次仍显示相同课表。
4. 重新导入后取消、网络中断、登录失效或空学期不会覆盖旧课表。
5. 退出教务登录后再次打开需要登录；已导入课表仍能离线查看。

构建标准版：`python android/build.py --sdk <SDK路径> --keystore <旧版签名密钥库路径>`。本次本地调试签名经核对与仓库旧 APK 不同，无法直接覆盖；需要旧版签名密钥才能提供可覆盖安装包，不要为安装而直接卸载旧版，以免丢失原有本机待办。

独立测试版：`python android/build.py --sdk <SDK路径> --preview`，生成 `nopalou-preview.apk`，应用 ID 为 `com.nopalou.preview`、名称为“楼外·课表测试”，可与原版并存，具有独立的本机数据和登录会话。它用于验证教务登录和课表功能，无需卸载原版，也不会把原版待办复制进测试版。测试课表无需给测试版开启通知读取权限。

# 撞车提醒规则

痛点：几个群的事常常堆在同一个晚上（周五 18:00 同时要交报告、报名、PPT），学生要等到当天才发现忙不过来。App 提前一周把"挤在一起"的事挑出来提醒。

纯逻辑放在 `com.nopalou.ClashPlan`，不依赖 Android。

## 1. 哪些卡参与

满足全部条件才参与：`done` 为假、`needsConfirm` 为假、`deadline > now`、`deadline <= now + 7 天`（按毫秒算）。考试卡和待办卡、接龙卡一视同仁。

## 2. 怎么算"挤在一起"

把参与的卡按 `deadline` 从早到晚排序，从最早的一张开始分组：一张卡和**前一张**的截止时间相差不超过 3 小时（含 3 小时整），就和前一张归入同一组，否则另起一组。

只有 2 张及以上的组算"撞车"。

## 3. 接口

- `static List<ClashPlan.Clash> find(List<Engine.Card> cards, long now)`：返回所有撞车组，按组内最早截止时间从早到晚排列。
- `ClashPlan.Clash` 有三个公开字段：`long start`（组内最早截止时间）、`long end`（组内最晚截止时间）、`List<Engine.Card> cards`（按截止时间从早到晚）。
- `String Clash.text()`：一句话说明，格式 `"{Engine.humanDeadline(start)}前后有 {N} 件事挤在一起：{标题}"`。标题取每张卡的 `displayTitle()`，用"、"连接；超过 3 张时只列前 3 张，后面加"等"。
- `static ClashPlan.Clash nearest(List<Engine.Card> cards, long now)`：最早的那一组，没有就返回 null。
